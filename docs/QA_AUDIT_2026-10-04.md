# AquaRelay demo audit — 4 October 2026

## Scope and evidence

The production build and 23 frontend unit tests passed. The backend suite passed 129 tests, with two PostgreSQL-specific concurrency tests skipped because no isolated PostgreSQL test URL was supplied. The 24 browser scenarios passed across the initial run and the corrected golden-journey rerun. Additional targeted checks verify Explore selection, filters, report creation and sharing after the performance changes. Browser tests used an isolated SQLite demo database and intercepted map tiles; they did not create demonstration reports in production.

Covered flows: account sessions and isolation; OTP UI retry/resend; real-map configuration and location selection; registry search, filters, pagination and passport navigation; historical events; approved spreadsheet import with missing-unit correction; report creation and evidence uploads; explicit case linking and additional evidence; scoped authority response and case resolution; notifications; offline draft replay; contacts and authority directory; three share formats and location pins; mobile layouts; loading intro; fullscreen gallery; reduced-motion, missing map modules and unavailable WebGL.

## Findings and fixes

1. **Slow Explore registry and filters.** A live request for 50 Bengaluru records took 9.8 seconds. Each lake's summary separately queried cases, observations, event source references and sources. Related records now load in batches for each result set. Workflow and date filters narrow records in SQL before summaries are calculated. Regression tests bound the page query count and compare batched summaries against the existing per-record output.
2. **Stale demo receipt selector.** The golden journey read the second receipt value as its case ID. Region and coordinates added to that receipt changed the ordering, causing a subsequent request to use the wrong ID and return 404. The test now finds the value beside the Case ID label. This was a test failure, not a lost production report.
3. **Map tile test fixture accuracy.** The golden journey's tile fixtures now include the cross-origin header needed by exported share-card canvases. Tests continue to avoid requesting community map tiles.
4. **Slow lake selection.** Explore requested detailed summaries of all nearby water bodies for a sidebar that did not display them. Sidebar, report identity and share-source requests now omit nearby summaries. Full passports still include nearby records, calculated in batches. Repeated sidebar selections reuse records for up to one minute, with live-event invalidation retained.
5. **Unnecessary graphics work.** The animated water background ran behind opaque internal pages. It now runs on the home page only. Map labels are capped at 80 visible names plus the selected lake, while the map's water-body points remain selectable.

## Remaining production requirements and limits

| Feature | Current limit / next verification |
| --- | --- |
| Email OTP, sign-in alerts and report checkpoint mail | Server reports email configured; automated delivery tests use mocked provider responses. Real inbox delivery and Google authorization longevity still need verification. |
| Browser push | Server reports available; actual device permission and delivery are not established by this run. |
| Automatic authority delivery | Public configuration reports configuration required. A verified recipient integration is needed; the directory alone does not establish institutional acceptance. |
| AI assistance | Live configuration is rules based. Generative AI is not configured; citizen report structuring does not send statements to Gemini. |
| Standards interoperability | Structural subset checks are implemented. This is not complete OGC/FHIR conformance certification. |
| Registry identities | OpenStreetMap starter records need local name, jurisdiction and connection review; geographic labels do not establish official names. |
| Performance on free hosting | Render can sleep after inactivity. Batching reduces database work but cannot remove the free service's cold-start delay. |
| Map/share images | Need access to OpenStreetMap tiles. Rendering fallback and retry are implemented; a fully disconnected browser cannot generate a fresh geographic image. |

A passing demo suite is evidence for these covered flows, not proof of every production integration or every possible input. No paid service or new API credential is needed for the fixes in this audit.
